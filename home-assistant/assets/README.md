# Shared Home Assistant assets

Store reusable public dashboard images, icons, backgrounds, and illustrations here.

For each asset or asset collection, record its purpose, source or generation method, and applicable license or usage restrictions. Keep editable sources when practical.

Use descriptive filenames and optimize image dimensions and file sizes for their intended display. Do not publish private camera snapshots, floor plans, personal photos, or screenshots containing home details without explicit authorization.

The active second-floor artwork belongs to [Roomcraft](../projects/roomcraft/docs/artwork.md), beside its renderer and user manual. The earlier presentation image and generation prompts are retained in the [legacy planning archive](../legacy/planning-illustration-2026-10-25/README.md); they are no longer the active dashboard reference.
