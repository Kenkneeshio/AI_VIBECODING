      HOW IT WORKS

      A little room to play.

      The overhead view uses the same rooms, furniture, and outdoor scene as the live dashboard.

      • Objects: search the catalog or choose a category, then click the plan to place one. Drag an object to move it, drag a corner to resize it, and use the Inspector for position, rotation, construction style, real-world size class, finish, and device links.
      • Furniture variants: Style changes the object's construction, Size applies that design's authored footprint, and Color / finish changes its material appearance without unexpectedly resizing a custom layout.
      • Dashboard interface: the sun/moon, clock, device menu, edit button, status badges, and all camera frames are ordinary editor items. Find them in Dashboard interface or Cameras & controls, then move, resize, rotate, duplicate, or remove them like furniture.
      • Artwork: choose Focus canvas to expand the plan; use the zoom buttons to inspect detail, then click the percentage to reset.
      • Lights: each room has a movable fixture. Enter its Home Assistant light or switch entity in the Inspector so the fixture itself becomes the dashboard control. A 4-pixel red/green dot shows the actual toggle state.
      • Camera: place a Camera thumbnail, assign camera and event-image entities, then drag and resize its frame. Latest event shows a still; Live uses a camera stream only when Home Assistant provides one.
      • Floors and rooms: choose a finish, then click a room; drag room corners in Room mode.
      • Walls and fences: choose Wall or Fence, then drag a line or tap its two ends. Use the Walls panel to select existing segments, drag their end handles, or edit coordinates and finish in the Inspector.
      • Layouts: browser edits save locally. When connected, the current Home Assistant layout loads on opening and is also the editor's reset target; a different browser draft remains recoverable. Select Save to publish your design, or download layout JSON to move it between browsers.
      • Home Assistant: Import from dashboard loads the published layout into Studio. Use Return to live dashboard beside Save. Unpublished edits are kept as a browser draft. PNG and YAML downloads remain available for manual setup.
