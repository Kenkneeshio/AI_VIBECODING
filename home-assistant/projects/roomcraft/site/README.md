# Roomcraft — Second Floor Builder

This package contains the shared Roomcraft editor and two authenticated Home Assistant transports. The **official** editor runs inside Home Assistant's `studio` dashboard view using `ha-local/roomcraft-card.js`; the owner-private cloud Site is an alternate route to the same saved layout.

- `public/editor.html`, `public/*.js`, `public/styles.css`, and `public/assets/` are the authored canvas editor.
- `ha-local/` contains the same-origin HA card, its tests, installer, and [LAN deployment guide](ha-local/README.md). `public/ha-iframe-bridge.js` connects the static editor to that card without exposing HA credentials.
- The HA card also supplies the authenticated `custom:roomcraft-camera-thumbnail` picture element. `lib/dashboard-elements.ts` keeps the cloud export's camera and control merge policy aligned with the HA card.
- `app/page.tsx` sends the Site root to `/editor`.
- `app/api/dashboard/route.ts` handles same-origin Home Assistant import/export requests.
- `dist/` is generated by the Vinext build and must not be edited or committed.

For the HA-hosted editor, follow the [LAN deployment guide](ha-local/README.md). For the optional cloud Site, install dependencies with the Sites `install-dependencies.mjs` helper, run `npm run dev` for local development, and use `build-site.mjs` for a deployable Worker artifact. The hosted runtime needs `HA_URL`, `HA_TOKEN`, and `OWNER_EMAIL` configured through Sites; never put credentials in source or browser code.

The Site remains owner-private under the project ID in `.openai/hosting.json`.
